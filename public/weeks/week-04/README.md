# Week 04 public assets

Files in this folder are served directly by the website at `/weeks/week-04/...`.

Use this folder only for what the live site must serve or link to for download: PDFs of reports, result screenshots, or small images referenced from `content/weeks/week-04.mdx`. Keep files small — everything here is bundled into the Vercel deployment.

Raw working files (notebooks, datasets, scripts) belong in `coursework/week-04/` instead, linked via GitHub.
