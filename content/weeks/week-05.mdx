## Assessment brief

The table shows the pathological test results for three individuals.

| Name | Gender | Fever | Cough | Test-1 | Test-2 | Test-3 | Test-4 |
|------|--------|-------|-------|--------|--------|--------|--------|
| Jack | M      | Y     | N     | P      | N      | N      | A      |
| Mary | F      | Y     | N     | P      | A      | P      | N      |
| Jim  | M      | Y     | P     | N      | N      | N      | A      |

Calculate Jaccard distance/dissimilarity for the following pairs: (Jack, Mary), (Jack, Jim), (Jim, Mary).

**Learning outcomes**

- Articulate the legal, social, ethical and professional issues faced by machine learning professionals.
- Understand the applicability and challenges associated with different datasets for the use of machine learning algorithms.

## Method

`Gender` is a symmetric binary attribute (M and F are equally informative outcomes), so it is excluded from the Jaccard calculation, which is designed for *asymmetric* binary attributes, where one outcome (a positive symptom or test result) matters far more than the other (its absence).

For the remaining six attributes, `Y` and `P` are coded as the positive outcome (**1**), and `N` and `A` are both coded as the negative/absent outcome (**0**):

| Name | Fever | Cough | Test-1 | Test-2 | Test-3 | Test-4 |
|------|-------|-------|--------|--------|--------|--------|
| Jack | 1     | 0     | 1      | 0      | 0      | 0      |
| Mary | 1     | 0     | 1      | 0      | 1      | 0      |
| Jim  | 1     | 1     | 0      | 0      | 0      | 0      |

For each pair, count:

- **q**: attributes where both are 1
- **r**: attributes where the first is 1 and the second is 0
- **s**: attributes where the first is 0 and the second is 1
- **t**: attributes where both are 0 (excluded, since a shared *absence* of a symptom is not treated as meaningful agreement)

```
d(i, j) = (r + s) / (q + r + s)
```

## Calculations

### Jack, Mary

| Attribute | Jack | Mary | Match type |
|-----------|------|------|------------|
| Fever     | 1    | 1    | q |
| Cough     | 0    | 0    | t |
| Test-1    | 1    | 1    | q |
| Test-2    | 0    | 0    | t |
| Test-3    | 0    | 1    | s |
| Test-4    | 0    | 0    | t |

q = 2, r = 0, s = 1

d(Jack, Mary) = (0 + 1) / (2 + 0 + 1) = 1/3 **= 0.33**

### Jack, Jim

| Attribute | Jack | Jim | Match type |
|-----------|------|-----|------------|
| Fever     | 1    | 1   | q |
| Cough     | 0    | 1   | s |
| Test-1    | 1    | 0   | r |
| Test-2    | 0    | 0   | t |
| Test-3    | 0    | 0   | t |
| Test-4    | 0    | 0   | t |

q = 1, r = 1, s = 1

d(Jack, Jim) = (1 + 1) / (1 + 1 + 1) = 2/3 **= 0.67**

### Jim, Mary

| Attribute | Jim | Mary | Match type |
|-----------|-----|------|------------|
| Fever     | 1   | 1    | q |
| Cough     | 1   | 0    | r |
| Test-1    | 0   | 1    | s |
| Test-2    | 0   | 0    | t |
| Test-3    | 0   | 1    | s |
| Test-4    | 0   | 0    | t |

q = 1, r = 1, s = 2

d(Jim, Mary) = (1 + 2) / (1 + 1 + 2) = 3/4 **= 0.75**

## Results

| Pair          | Jaccard distance |
|---------------|-------------------|
| (Jack, Mary)  | 0.33              |
| (Jack, Jim)   | 0.67              |
| (Jim, Mary)   | 0.75              |

Jack and Mary are the most similar pair (lowest distance): they share the same outcome on `Fever` and `Test-1`, and differ on only one positive result (`Test-3`). Jim and Mary are the least similar pair (highest distance): their positive results barely overlap, Jim's only positive findings are `Fever` and `Cough`, while Mary's are `Fever`, `Test-1`, and `Test-3`.

## Reflection on the learning outcomes

This exercise is a direct illustration of the second learning outcome: the choice of similarity measure has to match the structure of the dataset. Treating `Gender` as an ordinary binary attribute, or treating `N`/`A` as a meaningful "match" the way a symmetric measure like simple matching coefficient would, would have inflated every similarity score here by rewarding patients for *not* having a symptom in common, which is not clinically meaningful. Jaccard distance specifically ignores negative-negative matches for this reason, since in pathology data the absence of a test result or symptom is usually far less informative than its presence.

This connects to the first learning outcome as well. If this kind of patient-similarity calculation were used, for example, to group patients for diagnosis, treatment recommendation, or outbreak tracing, the choice to collapse `N` and `A` into a single "negative" category is a modelling decision with real consequences: it treats "tested negative" and "not tested" as equivalent, which may not be ethically or clinically defensible if the reason a test is absent matters (for example, a test that was not performed due to resource constraints rather than a conscious negative result). A professional dataset write-up would need to document that assumption explicitly rather than silently coding it away, since it directly affects any downstream clinical decision built on the resulting similarity scores.
